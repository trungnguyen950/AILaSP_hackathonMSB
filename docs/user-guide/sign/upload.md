# Ký Số — Upload file rồi ký

## Bước 1: Chọn biểu mẫu + chứng thư số

- Dropdown **biểu mẫu**: chọn 1 trong 9 mẫu MSB
- Dropdown **chứng thư số** (Mock USB Token): 3 lựa chọn

## Bước 2: Upload file biểu mẫu

- Kéo thả file vào khung **hoặc** click để chọn file
- Hỗ trợ: `.txt` và `.pdf` (tối đa 5MB)

## Bước 3: AI kiểm tra file

Nhấn **🤖 AI Kiểm Tra File** → Agent kiểm tra định dạng, mã mẫu, cấu trúc, nội dung.

## Bước 4: Vẽ chữ ký

Dùng chuột hoặc ngón tay vẽ vào khung canvas. Nút **🗑 Xóa** để vẽ lại.

## Bước 5: Ký & Xác Nhận

Nhấn **✍️ Ký File Đã Upload** → Agent chèn chữ ký, tạo hash SHA256, gửi webhook.

## Bước 6: Tải file đã ký

Nhấn **⬇ Tải xuống file đã ký** → file về máy. Kết quả hiển thị: file đã ký, SHA256 hash, webhook payload, trạng thái.
